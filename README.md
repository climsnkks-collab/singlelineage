# 싱글리니지

원본 클라이언트와 로컬 서버를 연결해 싱글 플레이 동작을 복원하는 진행 중인 프로젝트입니다. 현재 상태와 구현 방향은 [구현 계획](docs/IMPLEMENTATION_COMPLETION_PLAN.md)을 참고하세요.

이 공개 저장소에는 프로젝트 소스와 문서만 담습니다. 원본 게임 실행 파일·자원, 사용자 저장 데이터, 보존본, 빌드 산출물과 실행 로그는 포함하지 않습니다. 따라서 이 저장소만으로 게임을 실행할 수 없으며, 전체 원본 동작 재현이 완료됐다는 뜻도 아닙니다.

현재 세션 실행기와 Native 후보 소스는 `work/local_original_session/`에, 서버·bridge 및 관련 도구 소스는 `tools/`의 선택된 모듈에 있습니다. 로컬 작업 상태와 실행 근거는 공개 저장소 밖에서 관리합니다. Native 빌드가 참조하는 원본 추출 anchor 배열과 외부 Detours 소스도 공개본에서 제외했습니다.
