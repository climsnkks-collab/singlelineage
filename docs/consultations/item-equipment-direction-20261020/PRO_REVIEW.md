# 사용자 로그인 Pro의 ITEM-EQUIPMENT 방향 검토

2026-10-20. 기능 메인이 사용자 Chrome의 기존 로그인 상태와 실제 모델 메뉴의 **Pro(5/5)** 선택을 상담 전에 UI로 확인하고, 같은 공개 기능 brief와 최신 구현 범위를 제출했다. 최종 답변 및 완료 표시를 실제로 확인했다. 계정·선택 시각·대화 링크·UI 증거는 비공개 로컬 receipt에만 기록한다. 이전 비로그인 답변은 요청한 상담 완료로 인정하지 않으며 REVIEW.md의 철회 기록을 유지한다.

답변에는 고정 BRIEF commit76026ae와 공개 어댑터 commitcf5039c의 두 출처가 표시됐다. Pro는 GitHub 통합으로 두 본문을 읽었다고 명시하면서, 최신 제품 소스·역분석 계약·실게임 결과를 독립 검증한 것은 아니라고 한정했다. 공개 어댑터도 익명화된 제어흐름 자료로만 취급했다.

## 검토 결과와 채택 범위

- 원본 기반 클라이언트+로컬 서버 노선을 유지한다. 전체 클라이언트 소스화를 선행할 근거는 없으며, 기능 전체의 완료 소유권을 정리하고 현재 원 진입점의 Q1 경로를 실제 소비까지 완성하는 순서를 권고했다.
- Q1은 현재 선택된 source의 실제 수량이 하나인 경우다. 다수 스택에서 한 개를 요청하는 동작과 구분한다. Drop과 Get의 각 원 분기를 보존하고 Q1 성공을 다수수량 Popup·분할·취소의 완료로 확대하지 않는다.
- 핵심 후속 증거는 Drop 응답으로 생성된 실제 ground를 원 Get 선택이 소비한다는 연결이다. 원 요청, 중간 commit/readback, 응답 소비, Get 후 인벤토리 채택, 다음 정상 동작과 재선택/복원·정리를 같은 기능 묶음으로 확인한다. 시험 도구가 Get 요청을 직접 만들어 이어준 결과는 이 연결을 증명하지 않는다.
- 일반 Use의 backend 완료와 Manual 관측 수명은 분리한다. 동일 발급 intent/ordinal/operation의 검증, lease 종료, 완료 기록 공개가 다음 요청과 섞이지 않도록 처리한다. Receipt는 과거 backend 완료의 근거이며 현재 read 권한·Native 반환·client ACK·장비 표시를 대신하지 않는다.
- 늦은 관측과 중복 완료는 다음 요청의 lease·pending·선택·효과를 건드려서는 안 된다. 저장 후 전달 미확인은 반영 상태와 미확인을 함께 보존하며 재실행의 근거로 삼지 않는다. Receipt 소실이나 관측 기한 만료 때문에 원 Use를 반복하지 않는다. 기존 저장으로 복구 가능한 범위와 재시작 후 중복 방지 미확인 범위를 구분한다.
- 다음 NPC는 capture 허용을 넘어 실제 소비·상태 반영까지 확인하고, 그 이후 다음 Use 및 재선택/복원에서 장비 참조·효과의 일치와 중복 적용 부재를 이어간다. 실제 장비 표시·수치와 서버 효과·저장은 각각의 증거가 필요하다.
- 더 높은 원 UI 진입점은 누락된 필수 producer와 후보의 실제 owner/입력/부작용/정리 계약이 함께 확인될 때 선택한다. 가장 높은 주소가 아니라 필요한 계약을 포함하는 가장 가까운 원 진입점을 찾는다. Callback null만으로 producer 누락·시점·퇴역을 확정하지 않고, 기다리기나 dispatcher 재호출을 추측으로 추가하지 않는다.

## 다음 판정과 실행 경계

Q1 실제 왕복·다음 선택·복원/정리, 일반 Use→실제 장비/후속 기능→다음 Use/복원, 다수수량 Popup의 원 producer→부분 제출/취소→다음 동작을 각각 완료 단위로 유지한다. 기존 성공을 재사용하고, 다음 수정이 복원할 원 계약과 달라져야 할 최초 경계를 정할 수 있을 때만 추가 실행한다. 같은 최초 실패가 그대로이면 작은 guard 수정을 늘리지 않고 분기·producer·owner 가정을 재검토한다.

기능 메인은 이 의견을 원본 계약과 코드에 대조한다. 현재 Q1·Use 수명 구현은 이미 독립된 원본/소스·검사 근거가 있으며, 이 상담을 새 실행 권한이나 기존 결과의 소급 원인 확정으로 사용하지 않는다. 상담은 원본 동등성·실게임 성공의 증거가 아니다. 실제 문제 해결과 필요한 소스·기록의 본 작업 반영 후 기능 메인이 상담 브랜치를 정리한다.
