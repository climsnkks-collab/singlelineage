# 공식 몬스터 레벨과 언팩 NPC 데이터 비교

후속 유사성 조사: [레벨과 가장 관련된 필드](MONSTER_LEVEL_SIMILARITY.md)는 직접 정수 중 f19 signed32가 순위 상관-0.724275로 가장 강함을 확인했다. 이는 실제 레벨값/변환 공식이 아니며, f23을 공식 레벨로 사용하는 아래 추정 철회는 유지한다.

2026-10-09. **이전 3표본에서 레벨 후보로 봤던 `npc.bin` f23을 공식 몬스터 레벨로 사용하는 추정은 철회한다.** 전체 목록 비교에서는 거의 일치하지 않았다. 필드의 실제 역할은 원본 소비 코드로 추가 확인해야 한다.

## 비교 범위와 결과

[공식 몬스터 사전](https://lineageclassic.plaync.com/ko-kr/info/monster)의 공개 목록을 2026-10-09 19:28:23~19:28:28 KST에 새로 조회했다. 30행씩 12페이지, 첫페이지 재조회까지 13회 anonymous GET으로 351개 엔트리를 확보했다. 전체 ID는 고유하지만 이름은259종이므로 동명이름을 ID별로 보존했다. 조회 중 첫페이지 원문 SHA와 목록 정보는 동일했다.

비교 대상은 이미 인증된 클라이언트 `26.09.29.2001`의 `npc.bin` 951레코드다. 두 자료의 기준 시점이 다르며 동일 서버/버전을 가정하지 않았다. 현재 NPC 이름은 원문 f3의 $ID와 실제 desc.csv를 연결하고, 숫자는 원문 그대로 읽었다.

| 대응 조건 | 공식 엔트리 수 | f23과 공식 레벨 일치 |
|---|---:|---:|
| ID·한국어 이름 완전 일치 | 333 | **4 / 333 = 1.2012%** |
| 같은 ID, 이름 끝 공백만 차이 | 10 | 별도 보조 비교 포함 시 전체4 / 343 |

| 공식 전체 | 351 | 결측을0으로 채우지 않음 |

정확 대응333개 중 **329개(98.7988%)가 불일치**했다. 일치4개는 오크 ID0/156의2, 데스나이트 ID63 및 어둠의 데스나이트 ID10263의52다. 이 네 항목만으로 f23을 레벨로 명명할 수 없다. 정확 대응333개 중215개는 f23=1이다.

## 다른 숫자 필드와 구버전

현재 실제 기록된 정수필드9종(f1/f2/f19/f20/f22/f23/f24/f25/f26)을 동일한333개에서 비교했다. f23은4개, 0/1 값인 f26은 공식Lv1 두 항목에서2개가 같고 나머지7필드는 각각0개 일치했다. f19 부호 해석 후보도 레벨 일치0개다. ID·boolean·좁은 분류값의 우연 일치를 능력치 의미로 바꾸지 않았다.

옛 `26.08.28.2002` NPC 파일778레코드도 구조적으로 읽었다. 현재 정확 대응333개 중 같은 옛 ID의 f23이 존재하는 것은276개이고 공식 레벨과는3개만 같았다. 해골·좀비·커츠·바포메트의 예시 f23은 옛 파일에도 같다. 이 참조는 옛 한국어 이름/대상 정체성까지 확인한 대응이 아니므로 주 비교 분모에 넣지 않았다. 단순 최근 패치 차이만으로 현재 f23을 공식 레벨이라고 가정하지 않는다.

이 비교는 **현재 채워진 숫자 필드가 공식 레벨과 직접 같은 값인지**를 확인한 것이다. 원본 f23의 역할, 다른 파일의 레벨 자료, 서버 통지값, 변환/조회 구조까지 부재라고 증명한 것은 아니다. 공식 레벨은 출처와 시점을 보존한 별도 참조값으로 사용할 수 있지만 현재 숫자 필드의 이름을 임의로 바꾸거나 제품/서버 룰에 적용하지 않았다.
