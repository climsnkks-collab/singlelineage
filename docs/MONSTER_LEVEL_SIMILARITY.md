# 공식 레벨과 가장 관련된 언팩 필드

후속: [f19 코드 사용처·AC/lawful 가설 추적](NPC_F19_SEMANTICS.md)에서 파서/조회 ABI와 소비 경로를 확인했다. 현재 원본에서 사람용 의미는 아직 미확정이지만, 구버전 명명 데이터 대조는 AC보다 lawful/성향 가설을 더 강하게 지지한다. 아래 레벨 상관은 속성 이름의 증명이 아니다.

2026-10-09. **레벨의 높고 낮음과 가장 강하게 관련된 직접 정수필드는 f19다.** 실제 레벨값으로 확정한 것은 아니다. 공식19:28 스냅샷과 현재 NPC에서 ID·한국어 이름이 같은333개를 재사용해 비교했다.

## 직접 필드의 순위

| 필드 | 공식 레벨과 순위 상관(Spearman) | 확인한 읽기·분포 |
|---|---:|---|
| **f19** | **-0.724275** | signed32, 더 음수일수록 레벨이 높은 경향 |
| f22 | +0.491917 | 관찰값0/1/2, 의미 미확정 |
| f2 | +0.165543 | 정수, 의미 미확정 |
| f23 | -0.107943 | 공식 레벨로 사용할 근거 없음 |

상관의 크기는 숫자의 단위가 다른 필드 간에도 순서를 비교할 수 있다. f19의 부호를 뒤집어 `-f19`로 보면 같은 관계가 +0.724275가 된다. f1은 ID이고 f20/f24/f25/f26은 원본 bool 저장이므로 직접 레벨 후보 순위에서 분리했다. bool f24의 상관+0.502991는 두 집단의 레벨 차이를 나타낼 수 있지만 연속 레벨 수치라는 증거가 아니다.

f19는 현재333개에서 -1,000~200이다. 예를 들어 오크의 공식Lv2/f19=-2, 해골Lv10/-12, 데스나이트Lv52/-120이다. 값 자체는 공식 레벨과 다르다. 이름 끝 공백만 허용한343개에서도 상관-0.730965, 같은 이름·원문 프로필 중복을 제거한325개에서도-0.760456으로 관계가 유지됐다. 중복 제거는 공식 목록 순서의 첫 항목을 남긴 별도 민감도 비교이며 주333개를 대체하지 않았다.

## 숫자를 그대로 레벨로 쓸 수 있는가?

| 비교 방법 | 평균 절대오차(레벨) | 정확 일치 |
|---|---:|---:|
| f23 값을 그대로 사용 | 27.117 | 4/333 |
| `-f19` 사용 | 19.381 | 20/333 |
| 모든 항목을 공식 레벨 중앙값30으로 놓는 비교 기준 | 15.216 | 기준 성능 비교용 |

단순 값 차이로 가장 가까운 원시 필드는 f23이지만, 상수 기준보다 오차가 크고 레벨 순서와의 관련성도 낮다. f19도 부호만 바꿔서 레벨로 쓰면 상수 기준보다 오차가 크다. 따라서 **f19는 우선 조사할 연관 후보이며, 확정 레벨값이나 변환 공식은 아니다.** 비교 기준30을 제품/서버 값으로 넣지 않았다.

f21 목록에서 계산한 고유 첫값 수는 순위 상관+0.609775, 반복쌍 수는+0.548513이다. 이는 직접 저장된 레벨 정수가 아니라 목록 크기에서 파생한 값이다. f19 절댓값/로그 보기와 함께 통계를 보존했지만 조합식이나 보정식을 만들어 원작 공식으로 주장하지 않았다.

## 필드 인코딩과 정확 복원의 한계

원본 CommonNPCInfo serializer `69064D`는 object+80을 `movsxd rdx, dword ptr [rsi+80]`로 읽고 signed32를64비트로 부호 확장한 뒤 tag98(field19/wire0)로 기록한다. 크기 계산기 `690CF0`도 같은 필드를 부호 확장한다. 이전 원문 uint64의 큰 숫자는 이 음수의 비트 표현이다. **부호 있는 정수 읽기는 확인했으나 HP/AC/MR/EXP/레벨 중 어떤 속성인지는 미확정이다.** 기존 직접 GetNpc 호출자의 Level 문자열이나 같은 숫자 오프셋만으로 연결하지 않았다.

또한 ID를 제외한 **NPC 원문 프로필 전체와 이름이 동일하면서 공식 레벨은 다른7쌍**이 있다. 선택받지 못한 자2782/10204는36/39, 보초병2787/10209는37/40, 순찰병2807/10210은39/42다. 따라서 ID를 제외한 이 프로필 값만 받는 동일 변환함수는 해당 쌍의 다른 레벨을 구별할 수 없다. 다른 자료·서버 상태·버전 차이 가능성을 유지하며 언팩 전체 부재로 확대하지 않는다.
