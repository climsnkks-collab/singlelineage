# OWN NATIVE SUMMARY221 — 제공된 producer와 열린 입력

REA221 MAIN의 외부 전달용 OWN SUMMARY만 바탕으로 우리 문장으로 정리했다. 구체 native consumer 원문·주소·분해 결과·raw REA·바이너리는 포함하지 않는다.

기존 CharacterStore/roster는 정당한 저장 UID와 INFO의 class·gender 및 속성 순서 투영을 제공한다. 그러나 선정 baseline/CP73의 고정 profile은 SelfInfo와 Actor를 따로 구성하고 서로의 linkage를 확인하는 경로다. 이를 roster 전반을 임의 class로 변환하는 full converter로 간주할 수 없다.

실제 법사의 source-backed 현재 SelfInfo·Actor 입력, frame/grant·appearance authority를 발급하는 producer는 아직 미공급이다. 기존 encoder와 속성 투영 패턴은 재사용할 수 있지만 옛 초기값·knight/class0 외형값을 치환하거나 동료 UID/current generation을 추정해서 공급한 것으로 표시하지 않는다.

같은 Pro는 공급된 DTO 소비/core를 계속 구현한다. native 연결 완료 여부는 정당한 입력 출처와 실제 caller가 확보된 범위에서 판단한다. 새 원 RVA 발명·전체 save 탐색·임의 grant·새 native 실행/REA를 이번 문맥의 선행 작업으로 추가하지 않는다. 이 요약은 구현·실행 완료를 뜻하지 않는다.
