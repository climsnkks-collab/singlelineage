- 폐기한 자체 Win32/GDI 앱과 기존 원본 LC 기반 로컬 서버 시험 코드는 별개다. 후자의 frame/protobuf 처리, 캐릭터 store·route, 월드/이동 계약과 원본 분석은 현재 노선에서 재사용한다. REA는 필요한 통신·초기화·수명 경계를 해결하는 데 적용한다.
- 검증된 초기 통신·캐릭터·월드 경로를 우선 연결하고 필요한 메시지를 기능별로 확장한다. 전체 통신 규약·미사용 암호 모드·무관한 선택 필드의 완전 복원을 선행조건으로 만들지 않는다. 정상 입력의 원래 송신 경로를 우선하며 시험 도구의 외부 sender·시간 제한·증빙 조건을 게임 규약으로 혼동하지 않는다.

- 2026-10-15 사용자 결정과 범위 확인: REA 스킬을 사용하기 전에 자체 제작한 단독앱을 완전히 폐기한다. 현재 앱 소스·실행본은 삭제하고, 과거 검증 사본은 기록으로만 보존한다. 그 앱의 Win32/GDI 호스트·자체 UI·Runtime/Controller·별도 싱글 규칙 구현을 다시 제품으로 빌드·실행하거나 새 원본 재조립의 기반으로 재사용하지 않는다. REA 이후 원본에서 복원한 코드·ASM·렌더러·메인 루프·분석 자료는 폐기 대상이 아니다. 원본 클라이언트·원본 자원·사용자 저장 데이터도 보존한다. 과거 문서의 앱 실행 안내와 빌드 성공은 역사 기록이며 현재 제품 지시가 아니다. 상세 경계와 처리 결과는 [재조립 방향 검토](docs/REASSEMBLY_STRATEGY_REVIEW_20261015.md)와 최신 ACTIVE_TASK를 따른다.

- 제품 완료 기준은 PURPLE 실행·로그인이나 공식 게임 초기화에 의존하지 않는 싱글 단독 기동과 원본 클라이언트의 전체 동작 재현이다. 온라인 원본은 정상 접속·분석용으로 별도 보존한다.
- 원본 동작 재현 기준은 유지한다. 기능뿐 아니라 프레임·버튼 움직임·입력·화면 전환·자원 수명을 원본에 맞춘다. 구현 방법은 2026-10-16 선택한 원본 기반 클라이언트+로컬 서버 노선을 우선하며, 과거의 전면 재조립 문구를 모든 함수를 수작업 이식해야 한다는 조건으로 적용하지 않는다. 최소 기능·임의 UI/속도/애니메이션·정적 대체·일부 경로 생략을 전체 완료로 표시하지 않는다.
- 원본 클라이언트의 함수·상태·자원·caller/callee와 실제 소비 코드를 연결한다. 미확인 간접 호출·producer·미이식 분기는 열린 항목으로 유지하고 조사·이식을 계속한다. 파일 전량 읽기·해시·원문 바이트 일치·컴파일·자체 테스트 통과는 각각의 근거이며 전체 원본 동등성의 증명이 아니다.
- 기존 공개 서버 참고 규칙은 단독 backend의 출처 있는 별도 정책이다. 그 승인을 원본 frontend 동작을 임의로 대체할 허가로 해석하지 않는다. 원본 서버에서 확인하지 못한 규칙은 원본 동일로 주장하지 않고 차이를 기록한다. 중간 구현과 검증은 계속하되 전체 완료 판단은 이 기준을 따른다.
- 작업에 필요한 정상 온라인 접속·분석은 이미 사용자에게 승인받았다. 같은 범위의 승인을 반복해서 묻지 않는다. 새 범위나 외부 효과에 관한 별도 결정은 유지한다.
- 현재 문서는 현황과 계획의 인수인계다. 확인하지 않은 게임 진입이나 독립 실행을 완료로 표시하지 않는다.
- 메모리로 판별 가능한 준비·현재/대기 장면·전환 상태는 직접 메모리를 읽어 확인한다. 같은 상태를 사용자에게 화면으로 확인해 달라고 반복 요청하지 않는다. 읽기 실패·미확인은 unknown으로 유지하고, 메모리 상태를 실제 화면 표시나 게임 완료로 확대하지 않는다.
- `보관/`은 이전 작업의 보존 자료다. 보관본과 이전 원본을 임의로 변경·삭제하지 않고, 복사 중인 보관 작업과 충돌하지 않는다.
- 문서의 프로세스·방화벽·보관 진행 상태는 관찰 당시 값이다. 재개 시 다시 조회한다. PID만 보고 프로세스를 종료하지 않는다.
- 이전 분석 도구는 절대 경로·파일 해시·프로세스 식별에 묶여 있으므로 보관본에서 그대로 실행하지 않는다.
- 사용자가 말한 반복 승인 문제는 작업마다 뜨는 **Windows UAC**다. Codex 도구 승인 설정 문제로 바꾸어 설명하지 않는다. 최신 사용자 정정은 **UAC 금지가 아니라 가급적 창을 띄우지 않고 작업하라**는 뜻이다. 일반 권한 작업을 우선하고, 꼭 필요한 관리자 작업은 한 번 승인한 도우미에서 연속 실행·복구한다. 실패·취소 때 권한 창을 자동으로 반복하지 않는다.
- 재개와 종료 시 `docs/ACTIVE_TASK.md`의 최신 상태·근거·다음 작업을 갱신하고, 오래된 승인 문구나 과거 실패가 현재 상태로 오인되지 않도록 한다.
