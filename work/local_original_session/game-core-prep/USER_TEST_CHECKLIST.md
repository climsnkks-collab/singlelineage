# 오늘 밤 원본 기반 클라이언트 직접 시험 — 초안

2026-10-26 미커밋 소스 정적 확인 초안. **작성 중 게임·서버는 실행하지 않았다.** ‘연결’은 caller 존재이며 이번 조합의 화면 성공은 사용자 시험 전이다. 원본 클라이언트·자원+로컬 Python 서버/bridge 구성이다. 전투·회복·성장·드롭 등의 수치는 L1J 참고/로컬 정책이며 공식 클래식 서버 규칙으로 확정하지 않는다.

## 1. 기본 실행과 준비

다른 게임/로컬 시험을 정상 종료한 뒤 프로젝트 루트 PowerShell에서 사용자가 직접 실행한다. 기본 사냥 시험에서는 자세·HP바 강제를 켜지 않는다.

```powershell
& '.\work\local_original_session\manual-play\start-manual-play.ps1' -TestKnight
```

인수: `-World`·`-TestKnight` 기본 꺼짐(TestKnight는 World도 켬), `-Stance` 기본 -1=강제 없음, `-Hpbar` 기본0=꺼짐(허용0/1/2/3). 일반 저장으로 월드만 켜려면 `-TestKnight`를 `-World`로 바꾼다. 모두 생략하면 M1 월드가 꺼진다.

**기동 전 막힘:** 기존 고정 source 핀 때문에 수정본은 `PLAY_SOURCE_CHANGED:<파일>`로 멈출 수 있다. 코드/핀 통합 필요로 기록하며 임의 갱신·우회하지 않는다. `GAME_ALREADY_RUNNING`/`LOCAL_GAME_PORT_OCCUPIED`도 원문을 남기고 타 게임/포트 소유자를 종료하지 않는다.

저장은 `validation-profiles/manual-test-knight/`(일반 `manual-user-play/`와 분리). **새 프로필만** UID1 `SoloKnight` 남기사, STR/DEX/CON/WIS/CHA/INT=18/12/16/9/12/8로 만든다. 새 성장 기본은 Lv1/EXP0·HP20/20·MP10/10이며 기존 성장·좌표는 이어간다. **저장 인벤토리 행이 없을 때만** 아래19행 지급; 재실행은 초기화·재지급이 아니다.

- 첫 착용 4개: 장검3·큰 방패117·비늘 갑옷98·보호 망토109.
- 가방: 난쟁이족 철 투구89·티셔츠104·부츠128·장갑129 각1, 빨간 물약14×100·초록 물약17×20·용기의 물약296×20·아데나7×1000.
- 무기/화살: 단검41·양손검6·도끼4·창12·활11·참나무 지팡이230·화살29 각1. 기존 시험 저장에는 없을 수 있다. 없으면 해당 항목은 ‘준비물 없음’으로 남기고 저장을 지우지 않는다.

## 2. 한 번의 기본 플레이 순서

각 칸에 `성공/실패/미확인(준비물 없음)`과 첫 이상을 적고 앞 화면 확인 뒤 다음 조작을 한다.

1. [ ] **로그인·진입 [연결]**: 원래 로컬 로그인 조작→`SoloKnight` 선택→입장. 성공: 캐릭터·맵·HP/MP·가방이 나오고 조작 가능. 제한: PURPLE/공식 접속의 성공을 뜻하지 않는다. 콘솔의 실행 기록 경로를 보관한다.
2. [ ] **가방·방어구 [연결]**: 가방 버튼→수량 확인→미착용 투구·티셔츠·부츠·장갑을 각각 더블클릭해 착용/해제. 성공: 착용 표시 유지, AC가 있는 방어구만 수치 변화(티셔츠·장갑은AC0). 제한: 기존 저장은 지급표와 다를 수 있고 이번 UI 반영은 직접 판정한다.
3. [ ] **이동·몹 출현 [연결]**: 빈 땅 클릭으로 걷고 방향 전환. map0 마을 `(32578,32946)`에서 북쪽 `x32565~32625/y32856~32886`으로 이동. 성공: 배경·좌표가 따라가며 오크·고블린, 더 북쪽의 오크 궁수·늑대인간이 출현/배회. 제한: 근처 그룹 목표16마리의 로컬 배치다. 네 종 모두 비선공이므로 접근만으로 공격하지 않아도 정상이다.
4. [ ] **칼 전투 [연결]**: 장검으로 가까운 오크/고블린 클릭→공격, 이어 반복 공격·빈 땅 클릭해 중단하고 물러나 추적/반격 확인. 성공: 공격/피격 동작·PC HP 감소·몹 사망·공격 종료. 제한: 일반 몹 HP바는 기본 조건이 아니다. 공속/정적 차폐는 로컬 정책이며 동적 문/원본 시야 판정은 미확인이다.
5. [ ] **자연 회복 [연결]**: 안전한 곳에서 물약 없이60초 정지. 성공: 손실HP가 최대값 이내로 상승. Lv1 정지 약30초마다 CON16이면7 회복, 손실MP는 약16초마다 회복하는 로컬 정책이다. 제한: 가득 찬MP는 회복 미확인; 이동/공격은 느리게 회복한다. 저장값은 직접 고치지 않는다.
6. [ ] **물약 [연결]**: HP 손실 때 빨강, 이어 초록·용기 각각1회 더블클릭. 성공: 수량1씩 감소·HP 상승·걷기/공격 가속. 제한: 빨강 기준15+난수·최대HP 제한, 초록/용기 각300초(연장 상한1800초)는 로컬 정책이다. 주홍15·맑은130·강화초록495는 정상 보유 시만 같은 방식으로 확인하고, 비취126 해독은 독 틱 미연결로 미확인이다. 이펙트·원본 속도 동등성은 미확인이다.
7. [ ] **드롭·줍기·경험치/레벨업 [연결]**: 사냥 후 가까운 바닥 아이템 클릭. 성공: 바닥에서 사라지고 가방 증가, 처치 때EXP % 증가·누적125에서Lv2/최대HP 상승. 최대MP 변화도 기록(기사는 불변 가능, 현재값 자동충전 없음). 근처에 머물러 시체 약50초 뒤 정리→그 뒤60~120초 후 재출현도 본다. 제한: 확률 드롭·미해결 품목 제외, 거리≤3칸·우선권10초·만료600초는 로컬 정책이다. 바닥 재기동 복원 없음, 성장표Lv1~30.
8. [ ] **무기 자세·화살 [연결, 화면 재확인]**: 안전한 곳에서 장검→단검→양손검→도끼→창→활→지팡이를 더블클릭 교체해 정지/이동 자세 확인. 활로 몹에 한 발 쏜다. 성공: 무기/자세 일치·화살29가1→0/제거, 다음 발은 피해 없음(빗나가도1 소모). 제한: 화살29만 지원, 피해6/5·활 사거리는 L1J fallback; 비행 그림·원본 사거리·창 장거리 미확인. 다시 장검 착용.
9. [ ] **사망·Restart [연결]**: 확인을 마친 뒤 반격받아HP0→원래 Restart→재선택. 성공: 죽은 동작·이동/공격 중단, 마을 `(32578,32946)` 최대HP 복귀. 제한: 제자리 부활 대신 재선택하는 로컬 정책이며Lv1~10 경험치 손실0. 장비 유실은 범위 밖이다.
10. [ ] **마을 NPC·상점 [외형 연결 / 대화·거래 미연결]**: 마을NPC 클릭. 외형/이름 표시를 확인한다. 거래 성공 모습은 메뉴→구매/판매→품목·수량1→확정→재화/가방 증감이다. **기본 `world_handler_sources=()`라 실제 메뉴가 없어 현재 완료 판정 불가**. 데이터·계산·핸들러 source만으로 성공 표시하거나 직접 재화를 바꾸지 않는다.
11. [ ] **주문서 [사용 연결 / 준비물 조건부]**: 정상 보유한 귀환162/순간이동23 더블클릭→재선택. 성공: 수량1 감소·귀환은 마을/순간이동은 같은 맵 새 좌표. 제한: 키트에 없고 기본 상점도 미연결이므로 없으면 미확인. 즉시 전송 wire UNKNOWN으로 Restart→재선택 fallback; 랜덤 반경200 통행칸은 로컬 정책이다.
12. [ ] **30분 순환·종료/복원 [일부 연결]**: 장검 사냥·줍기를 합쳐30분→원래 Quit→콘솔 종료 뒤 같은 명령 재기동·선택. 성공: 위치·장착·가방·EXP/레벨·최대HP/MP 유지, 다음 사냥 가능. 제한: 현재HP/MP는 프로세스 메모리여서 새 기동 손실량 보존 미지원, 가속은 선택 종료 때 끝난다. 강제 정리는 정상 종료로 적지 않는다.

## 3. 기본 시험을 닫은 뒤 별도 재기동 실험

**자세:** 무기별 기본값은 맨손0(미확인), 검30·도끼/둔기35·활40·창45·단검55·양손검60(사용자 확인 기록), **지팡이120(후보·미확인)**. 50은 도끼처럼 보였던 값이다. 기본 실행의 참나무 지팡이 착용으로120 정지/이동/공격을 먼저 본다. 강제 비교는 정상 Quit 후 아래 실행(숫자120을 바꿔 변경). `-Stance`는 **자기 캐릭터 자세를 무기와 무관하게 같은 값으로 강제**하므로 장비별 성공과 구분한다. 복귀는 생략 또는 `-Stance -1`로 재기동.

```powershell
& '.\work\local_original_session\manual-play\start-manual-play.ps1' -TestKnight -Stance 120
```

**HP바 [실험 연결·의미/화면 미확인]:** 정상 Quit 후 아래 실행→몹 선택·실제 피해 한 타격→머리 위 바/수치 관찰. `1`=4F1A f4, `2`=4F1A f2, `3`=4EC8 표시/비율 가설. caller는 **매번 첫 단계100만** 보내므로100→50→1·숨김 단계는 시험 불가이며 후보100은 실제HP가 아니다. 정식 HP바 성공으로 표시하지 않는다. 비교는 정상 종료→`-Hpbar 2`, 다시 정상 종료→`-Hpbar 3`; 각 화면을 따로 기록. 기본은 생략/0.

```powershell
& '.\work\local_original_session\manual-play\start-manual-play.ps1' -TestKnight -Hpbar 1
```
