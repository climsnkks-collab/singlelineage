## 실행

다른 게임을 정상 종료한 뒤 프로젝트 루트 PowerShell에서 실행한다.

```powershell
& '.\work\local_original_session\manual-play\start-manual-play.ps1' -TestKnight
& '.\work\local_original_session\manual-play\start-manual-play.ps1' -TestKnight -CompanionBridge
```

`-TestKnight`는 월드와 기사 시험 저장(`validation-profiles/manual-test-knight/`)을 사용한다. 새 프로필은 SoloKnight 남기사(18/12/16/9/12/8). 기존 저장은 이어가며 지우지 않는다. 일반 `-World`는 사용자 저장을 사용하고, 옵션을 모두 생략하면 월드가 꺼진다.

인벤토리 저장이 없을 때만 첫 키트 지급: 장검·큰 방패·비늘 갑옷·보호 망토 착용, 투구·티셔츠·부츠·장갑은 가방. 빨강100·초록20·용기20·아데나1000, 단검/양손검/도끼/창/활/지팡이 각1·화살200, 변신 주문서5·귀환10·순간이동10, 무기/갑옷 강화 주문서 일반·축복·저주 각5, 부활 주문서10. 동료에게 줄 가죽 갑옷·투구·오크족 망토·짧은 부츠·작은 방패 각1도 가방에 지급하며, 동료 설정에서는 파란 물약20을 추가한다. 옛 저장에 없으면 ‘준비물 없음’으로 남긴다.

`-TestKnight -Companion`은 새 시험 프로필에 SoloMage 남법사를 만든다. 캐릭터 선택 화면에서 **SoloMage를 직접 선택해 접속**할 수 있다. 새 법사 가방은 단검·가죽 재킷·빨강100·초록50·아데나100에 **마법서16종 각1권·파란 물약20·말하는 두루마리1**을 더한다. 같은 법사의 가방을 동료 소환과 직접 접속이 공유한다. 새 지급은 저장 인벤토리가 없는 법사에만 적용되며 기존 생성 캐릭터의 저장 가방에는 소급 추가하지 않는다. 동료로 쓰면서 이미 소비·학습한 책은 직접 접속해도 원래 수량으로 돌아오지 않는다.
