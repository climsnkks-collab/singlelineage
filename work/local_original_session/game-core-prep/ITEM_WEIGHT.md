# M1 아이템 무게 입력

2026-10-26. 기존 `tools/local_original_session/data/m1/items.json` 35행에 `weight`만 추가했다. 기존 값·행 순서·메타데이터는 그대로 두었고, 요청 경로·모듈·저장·게임·서버는 변경하거나 실행하지 않았다. 모든 값은 `source=l1j`인 **L1J 참조 로컬 backend 정책**이다. native 무게 의미·단위를 이번 자료로 확정할 수 없어 사용자 허용 fallback을 적용했다.

## 소비 단위와 변환

- `tools/local_original_session/world_weight.py`의 `RAW_PER_WEIGHT`, `weight_catalog`, `load_weight_catalog`는 `weight.value`를 음이 아닌 **raw 정수**로 읽고 `value/source/ref/note` 출처를 보존한다. `load_items`로 읽은 기존 ItemDef를 사용한다.
- SQL `weight` 원값을 배율 변경 없이 입력한다. 1000 raw가 backend 부담 1에 해당한다. 실제 하나의 스택 수량을 `Q`, SQL 원값을 `R`이라 하면 `R=0`일 때 0, 그 외 `max((R*Q)//1000, 1)`이다. 템플릿별/낱개별 선반올림을 하지 않고 각 인스턴스 스택 결과를 합산한다.
- 근거는 `D:/SingleLineageRef/l1j-en-classic/src/l1j/server/server/model/Instance/L1ItemInstance.java:252-257`와 `model/L1Inventory.java:66-71`이다. 기존 `work/local_original_session/integration-1/warehouse-unit-weight-source-v1/API.md`의 unit RAW 계약과 빨간 물약14→etcitem40010 raw3900, 아데나7→etcitem40308 raw0도 그대로 재사용했다.
- 예: 빨간 물약 raw3900은 Q1/Q2/Q10에서 부담 3/7/39다. 화살 raw30은 Q1에서 최소 1, Q100에서 3이다. 아데나는 SQL의 명시적 0이며 unknown의 대체값이 아니다. 수량·현재 인벤토리·소유권·입수 허용 여부를 이 데이터가 인증하지 않는다.

## 대응 선택과 native 경계

`MAPPING_SCOPE.md` 3장과 기존 `data/catalog/items_all.json`의 `mapping.candidates[].stats.weight/raw_sql`을 재사용했다. 선택은 **기존 M1 각 행의 stackable 출처에 명시된 정확한 SQL 줄**과 동일한 후보이며, 새 ID 대응이나 축복 변형을 만들지 않았다. 아래 35개는 모두 그 기존 L1J 일반(bless=1) 행이다. 한국 이름·이름토큰·종류는 기존 M1/catalog 대응에 따른다. 장검($5→L1J $0), 빨간 물약($237→L1J $26)처럼 기존 명시 대응의 토큰 차이는 유지한다. native 축복/일반/저주 해독이나 고유 변형 선택을 확정한 것은 아니다. 후보가 복수인 행도 기존 선택을 따르며 해당 행의 후보 간 raw 무게 차이는 없다.

`work/all_table_semantics/item/README.md`에서 f10은 price/value **후보**이며 실제 소비 의미는 미확정이다. `ITEM_CATALOG.md`와 catalog method 역시 f10/SQL weight의 수치 비교만 인정한다. f15는 수량 집계 인수, f26은 `(Q*f15+64)>>7` 보정 boolean이라는 별도 기존 소비 계약이다. f15/f26을 SQL 무게로 변환하거나 f26을 stackable 증명으로 사용하지 않았다. 아래 f26의 `부재`는 0/false로 보충하지 않았다.

35행 중 native f10과 선택 SQL weight는 **30행 수치 일치, 5행 불일치**다. 아탐(10000/10000), 가죽 갑옷(70000/70000), 아데나(0/0)는 일치 예다. 나무방패(25000/30000), 초록 물약(4688/3900), 용기의 물약(9375/4500), 빨간 물약(5859/3900), 화살(47/30)은 불일치한다. 따라서 보편 배율이나 native 단위를 확정할 수 없으며, 일치 30행 역시 native 인간용 무게·소비 증거로 승격하지 않았다. 특히 f26 사용 물약/화살의 수량 집계와 L1J 부담식을 합치지 않았다.
