# 영상 실험 노트: 언데드 추가 타격(언추타) / 마법방어·속성저항

수집일 2026-10-30. 출처는 두 영상의 유튜브 자동 생성 한국어 자막(ASR)이다. 자막에 오인식이 섞여 있어(예: "요정족단검"이 "요정 단검"으로, "수령"이 "수룡"의 오인식으로 보이는 등) 숫자 위주로 정리했고, 어긋나 보이는 곳은 "확인 필요"로 표시했다. 영상 화면(표·그래프)은 직접 보지 않았다. 스크린샷 두 장 정도만 확인했고, 자막과 설명란·댓글 텍스트가 근거의 전부다.
채널 "별모양" 주장이며 클라이언트가 아닌 사용자 실측이다. 원작(리니지 클래식, 서버 소스) 검증은 하지 않았다.

## 영상 1: 언추타 (언데드 추가 타격치)

- URL: https://www.youtube.com/watch?v=W_eXF7x4dx0
- 제목: 리니지클래식 언추타 1~10? 전부 틀렸습니다
- 채널: 별모양 / 업로드 2026-10-29 / 길이 4분 46초
- 설명란: 언데드 추가 타격치 분석 자료, 장비 세팅 참고용. 숫자는 없음(해시태그만).
- 고정 댓글: 작성자의 질문("지금까지 알던 언추타 수치는?"). 숫자 정보 없음. 다른 댓글 중 한 줄 요약: "1강마다 언추타 최대 대미지 +1".
- 자막: 3개 트랙(en/id/ko ASR) 중 ko를 읽음. 전체 확보.

### 실험 조건
- 목표: 소문(언추타는 1~10 랜덤, 또는 1~20 랜덤)을 몬스터 HP 변화로 실측해 검증. 라이브 방송 3일, 총 1,000회 이상 타격.
- 대상: 좀비(언데드). 본캐 법사가 좀비를 테이밍해 HP를 실시간 추적.
- 공격자: 힘 추타 +1 상태인 5레벨 보조 기사(스탯 변수 제거 목적).
- 사전 검증(환경 보정): 언추타 옵션이 없는 넓은 검(발음상 "와이드 소드류"로 추정, 확인 필요)으로 좀비를 100회 타격 -> 데미지 최소 2, 최대 5. 설명: 무기 기본 데미지 1~4 + 힘 추타 +1 이 그대로 합산, 좀비에게 별도 데미지 리덕션 없음.
- 본 실험 무기 1: 요정족단검(영상 표현 "작은몹 데미지 4인 요정 단검"). +0부터 +6까지 +1씩. 재질은 영상에서 "은이나 미스릴 재질"로 일반화해서 말함. 축복/일반 구분은 언급 없음.
- 본 실험 무기 2: 메일 브레이커(실전용 대표 언추타 무기라고 소개). +0, +8, +9 측정.

### 실측값
| 무기 | 실측 데미지 | 환산 |
|---|---|---|
| 요정단검 +0 | 3~15 | 기본 2~5(힘추타 포함)를 빼면 언추타 1~10 |
| 요정단검 +6 | 최대 27 | 무기 4 + 힘추타 1 + 강화추타 6 = 최대 11 이므로 언추타 최대 16 |
| 메일 브레이커 +0 | 3~15 | 요단 +0과 동일하게 언추타 1~10 |
| 메일 브레이커 +8 | 최대 31 | 언추타 최대 18 |
| 메일 브레이커 +9 | 최대 32 (표본 47타) | 언추타 최대 18 이상. 표본이 적어 양 끝값은 다 안 나왔다고 작성자가 인정 |

- 요단 +1~+5, 메일 +1~+7의 개별 수치는 자막에 없음.
- 메일 브레이커 +8: 31 - (무기 기본 최대치 15 - 10 = 5 에서의 관계는 영상이 설명하지 않음). 영상은 "순수 언추타가 18까지 상승"이라고만 말함. 환산식은 확인 필요.

### 작성자 결론 / 공식
- 은 또는 미스릴 재질 무기의 언추타 최솟값은 강화와 무관하게 항상 1로 고정.
- 최댓값은 기본 10에 무기 인챈트 수치가 그대로 더해진다.
- **언추타 = 1 ~ (10 + 인챈트), 균등 랜덤으로 추정(분포 형태는 영상에서 말하지 않음. 확인 필요).**
- 따라서 고강화 무기는 "강화 추타 +1/강"에 더해 "언추타 상한도 +1/강"의 이중 효과.
- 최종 타격 = 무기 기본 데미지 + 힘 추타(등) + 강화 추타(+인챈트) + 언추타[1, 10+인챈트] (각 항 합산으로 해석됨. 작성자가 한 줄 식으로 쓰지는 않았지만 +6 요단 최대치 계산이 이 합산을 따름: 4+1+6+16=27).

### 확인하지 못한 점
- 요정족단검과 메일 브레이커의 재질/축복 상태 표시, 사용 몬스터 외 언데드 종류. 좀비 한 종류만 언급.
- 인챈트 +10 이상, 축복 무기, 다른 언추타 무기(예: 수치가 다른 무기)의 동작.
- 언데드 추타가 대미지 감소(마방/속성/AC)와 어떻게 상호작용하는지.
- 영상 화면에 나온 표/그래프는 읽지 않음.

## 영상 2: 마법방어(MR) / 속성저항

- URL: https://www.youtube.com/watch?v=JRmq8W2UQ8Y
- 제목: 리니지클래식 마법방어/속성저항 완벽 분석
- 채널: 별모양 / 업로드 2026-10-24 / 길이 6분 4초
- 설명란: 마법방어(MR)와 속성저항 분석 자료, 장비 세팅 참고용. 장비 지원: 로엔그린 "머개"님. 숫자는 없음.
- 고정 댓글: 사냥터·마방/속성저항 세팅 공유 요청. 숫자 정보 없음.
- 자막: 한국어 ASR 전체 확보(136줄).

### 실험 조건
- 공격 마법: 아이스 대거(수속성). 시전자: 42레벨 위즈 인트 18, SP 12 상태의 법사.
- 피격자의 마방(MR)과 속성저항 조합을 바꿔 가며 조건당 100회, 총 800회 측정.
- 마방 30% / 50% / 70%. 속성저항 30% / 50% (수룡 반지, 물정령 벨트, 청명한(수룡?) 갑옷으로 구성. "용가옷"/"수령 갑옷" 표기는 ASR 오인식 가능성, 확인 필요). 복합 세팅 2종: 마방 35%+속성 30%, 마방 50%+속성 30%.
- 영상은 "마방 70%까지 올린 세팅보다 사냥터에 맞춘 속성 반지+정령 벨트가 데미지를 더 줄인다"고 요약.

### 실측값 (아이스 대거, 평균 데미지)
| 조건 | 평균 | 감소율(무장비 대비) | 비고 |
|---|---|---|---|
| 무장비(마방 0, 속성 0) | 18.2 | 0% | 최대 27, 최소 11 |
| 마방 30% | 약 14.5 (계산) | 20.5% | 마방 1%당 약 0.68%p 감소 |
| 마방 50% | 13.3 | 약 26.9% (30%에서 +6.4%p) | |
| 마방 70% | 약 12.0 (계산) | 약 34.1% (50%에서 +7.2%p) | 최소 데미지는 8 미만으로 안 내려감 |
| 속성저항 30% | 11.7 | 35.9% | 최소 데미지 5까지 하락 |
| 속성저항 50% | 약 8.8 (계산) | 51.4% | 영상은 "절반 이하" |
| 복합 마방 50% + 속성 30% | 실측 9.14 | 약 50% | 공식 예측 9.26, 오차 약 0.12(영상은 "약 0.15" 수준이라 말함) |
- "계산"이라 적은 값은 영상이 직접 말하지 않고 감소율에서 내가 역산한 것이다.
- 마방 35%+속성 30% 복합 세팅의 결과값은 자막에 없음.

### 작성자 주장 / 공식
- 마방: 30%까지는 효율이 좋고, 50%를 넘으면 추가 1%당 감소폭이 0.3%p 미만으로 급감(체감 구조). 마방을 30/50/70으로 올려도 최소 데미지는 동일(8 아래로 안 내려감) -> 마법 자체에 데미지 하한이 있어 평균 감소폭이 점점 줄어든다고 설명.
- 속성저항: 단일 아이템 최대는 용갑옷 계열 20%. 속성 반지 2개 + 속성 벨트로 30%를 쉽게 만들 수 있음. 평균을 깎을 뿐 아니라 최소 데미지 하한 자체를 낮춤(30%에서 최소 5).
- 결합 방식: **독립 곱연산.** 최종 마법 데미지 = 원래 데미지 x (마방에 의한 감소 비율) x (속성저항에 의한 감소 비율).
- 단, 수치 검산(내 계산, 영상 주장 아님): 마방 50% 평균 13.3(비율 0.731)과 속성 30% 평균 11.7(비율 0.641)을 곱하면 18.2 x 0.731 x 0.641 = 약 8.5로, 영상의 예측값 9.26과 맞지 않는다. 9.26은 13.3 x 0.70(속성저항 30%를 그대로 30% 감소로 적용) 와 거의 일치한다(9.31). 즉 영상의 "공식 예측"은 속성저항 수치를 감소율로 직접 곱한 것으로 보이며, 단독 측정치(35.9% 감소)와 일관되지 않는다. 이 불일치를 영상은 설명하지 않았다. 구현 시 속성 감소를 30%로 볼지 35.9%로 볼지 확인 필요.
- 실전 가이드(결론): (1) 마방은 30~50%까지만 맞추는 것이 가성비. (2) 특정 속성 몬스터 사냥터에서는 고강화 마방템보다 속성 반지 2개+속성 벨트가 무조건 유리. (3) 복합 세팅 마방 50%+속성 30%의 데미지 감소는 약 50%.

### 확인하지 못한 점
- 마방 수치(%)와 아이템 MR 수치/INT 보정 사이의 환산식(영상에서 "마방 70%" 같은 퍼센트 표기만 사용, 원작 MR 공식 없음). 화면 한 장에 "마법 저항력(MR)=10+12" 같은 툴팁이 비치나 해독하지 못함.
- 아이스 대거 외의 마법, 다른 속성(화/풍/지), 속성저항 상한(캡), 속성저항 1포인트당 정확한 환산. 상한/캡은 영상에서 언급 없음(50%까지만 시험).
- 데미지 하한(마방 쪽 8, 속성 쪽 5)의 정확한 산식.
- 영상의 그래프/표는 읽지 않음.
