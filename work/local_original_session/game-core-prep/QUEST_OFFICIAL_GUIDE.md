# 공식 가이드 퀘스트 목록 대조

확인일: 2026-10-28. 고정 클라이언트 비교 기준은 `native-dump-v1.jsonl`의 **26.09.29.2001**이다. 공식 현행 가이드를 고정 버전의 서버 계약으로 소급하지 않는다. 이 문서는 조사 목록이며 실행 등록·소켓 PASS를 뜻하지 않는다.

공식 가이드의 실제 [전체 분류 API](https://lineageclassic.plaync.com/api/v2/lineageclassic/categories?gwLocale=ko_KR)와 퀘스트 분류4541을 확인했다. 퀘스트 하위 문서는 레벨6576·토템6577·해적섬6714의 3개다. 마을4546·아이템4549·컨텐츠4562도 확인했고, 컨텐츠의 카리프6639를 교환 후보에 포함했다. **16 직업 단계 + 토템1 + 해적섬6 + 카리프6 = 29 후보 행**이며, 단계·교환 선택지 수와 독립 퀘스트 수는 다르다. 검색 미색인을 부재 근거로 사용하지 않았다.

공식 전체 분류 **상위12개·고유 가이드61개**의 제목/ID/category ID는 `../runs/quest-catalogue-20261028/guide-index.json`에 보존했고,61개 본문도 제목별 JSON으로 읽었다. 퀘스트·전달 관련 문단14개는 `guide-quest-matches.json`에서 재확인할 수 있다. 일반 기능 설명과 펫 먹이주기는 새 퀘스트로 세지 않았다. 원문은 같은 폴더의 `categories.json`, `category-{id}.json`, 각 제목의 JSON에 보존했다. 페이지가 HTML shell만 반환할 때는 페이지 자체 스크립트가 사용하는 `/api/v2/lineageclassic/guide/{제목}?gwLocale=ko_KR`로 읽었다. 코드·원본·사용자 저장은 변경하지 않았다.

## 근거 등급

- **O1**: 공식 가이드가 NPC·진행·재료/단가·보상 흐름을 명시하고 고정 자료가 대응한다. 실제 구현의 배치·드롭 variant·화면 계약은 별도 검증한다.
- **O2**: 공식 이름/시작/보상은 있지만 수량·단계·생산자·소비 중 일부가 미확인이다.
- **O3**: 공식 현행에는 있으나 고정 버전 이후 추가 또는 고정 자료 대응 부재다.
- **E**: 기간 이벤트. 고정 데이터 존재와 상시 실행 가능성을 구별한다.

## 기타 공식 대조 경계

마을 소개는 NPC의 의뢰/제작을 일반적으로 설명하지만 마을 심부름 이름·재료·보상을 추가로 제시하지 않는다. 아이템 문서의 제작 NPC/결과 목록에는 네루파·페어리·브롭 등 제작 경로가 있으나 재료 수량이 없어 완결 퀘스트로 세지 않았다. 개별 사전의 NPC 제작처/퀘스트 물품 설명은 고정 전체 목록 `QUEST_CATALOGUE.md`에서 각각 교차대조한다.

공식 목록만으로 닫힌 신규 전달·고정 처치수 계약은0개다. L1J 수량이나 후속 버전 보상을 빈칸에 채워 공식으로 표시하지 않았다. 이 조사로 확인한29행을 실행 등록29개 또는 원본 플레이 완료로 표현하지 않는다.
