## 드롭 대응과 미확정

후속 검토 수정: 수정 전 총집계는 roll 140/unresolved 37이었으나, M1 네 종의 미확정7행을 그대로 복사했다는 설명과 달리 그7행이 다른 NPC/item의 local_policy fallback으로 roll에 들어 있었다. 이7행을 미확정으로 되돌려 최종 roll 133/unresolved 44로 정리했다. 현재 M1 전체 내용과 같다는 주장은 철회하며, 병행 변경 중인 M1의 내용 복사를 완료 근거로 삼지 않는다.

M1이 병행 수정되고 있어 현재 파일 내용의 동일성이나 미확정 원행 복사 상태를 기준으로 삼지 않는다. 처음 M1 분석의 같은 NPC·호환 아이템·등급 원칙과 빨간 물약14↔L1J40010, 장검3↔weapon31의 identity 예외 근거만 재사용했다. 복사된 M1 local_policy fallback7행(오크 창1·고블린3·늑대인간 둔기3)은 다른 NPC 또는 다른 아이템의 확률을 전용하므로 제거하고 unresolved로 복원했다. 제거한 roll 원문은 unresolved/rejected_roll에 보존했다. M1 파일은 수정하지 않았다.
