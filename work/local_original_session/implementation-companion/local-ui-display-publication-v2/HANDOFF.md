The exact existing LUI2 parser validates the actual received names/levels/phase/reasons/support fields. It copies the parsed value into this slot, erases its parsing temporary and never retains a receive-buffer/stack pointer. The slot is immutable while an owner reads it. Worker is bound by Begin on the exact one-attempt Session thread; a foreign thread cannot publish or bind the established owner.

The new LOCAL display-retention maximum is **250ms from native receipt**, clipped to the remaining original Session deadline. This is an explicit historical-display retention policy, not the server's 250ms OwnerSample evidence, a server lease or live selection/command authority. It does not restamp or change server evidence. Owner access checks actual GetTickCount64 immediately before exposing the projection. Expiry zeroes the owned slot and all observed display metadata. Model replacement increments epoch and removes the prior observation; withdrawal clears bytes and increments epoch under the same lock.

`VisitOnOwner` lends a const reference only for a bounded synchronous pure visit under that lock. No reference/copy may escape, and the visitor must not wait, reenter, call User32, publish callbacks or dispatch commands. The actual mailbox consumer digests every display byte during the visit and keeps only sequence/count/digest history, never a model cache. Withdrawal linearizes after any in-flight bounded visit; after withdrawal returns no old projection can be visited. This is an internal native ownership contract, not an API for arbitrary plugins. A renderer still needs its own reviewed painting/clear integration and native receipts; it cannot put User32 inside this locked visitor or treat the digest as permission to paint later.

`ui_owner_mailbox.hpp` binds/observes publication only after the existing established-owner test and during its original OnOwner entry. The IO worker performs **no new User32 call or wake**. A parked owner therefore has an explicit older `owner_observed_epoch`; publishing, expiring or withdrawing does not fabricate owner processing. The next genuine owner callback observes the new epoch.
